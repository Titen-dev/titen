Overview

Titen is an AI agent that reads the world's signals and tells you what matters, with every source attached. It has five abilities:

FeatureWhat it doesWebCLI
Trend RadarThe most important stories right now, from Google Trends, news feeds, Hacker News and GitHub✓ global✓ any region
Daily BriefThe last ~48 hours of news on a topic, in a few lines with sources✓ 20 topics✓ any topic
TL;DRThe point, key facts and what's missing from any readable page✓✓
Scam CheckIs a message, link or screenshot a scam? Verdict, red flags, next steps✓✓
WatchWatch a page or topic and get a desktop notification when it really changes–✓

Summaries are written by an AI model through OpenRouter. Titen only cites sources it actually collected, so it can't invent links.

Using the website

No account or install needed. Open titenhq.com and:

  • Radar shows the stories the world is watching, refreshed every few hours.
  • Brief: pick up to six topics. Your choice stays in your browser.
  • TL;DR: paste a link to an article.
  • Scam Check: paste a message, a link, or drop a screenshot. Links are analyzed but never opened.

Install the CLI

You need Node.js 20.12 or newer and an OpenRouter API key (the CLI uses your own key and credit).

npm install -g @titen-dev/titen
titen setup

titen setup checks your key with OpenRouter and saves it to ~/.titen/config.json. Then try:

titen trends

CLI commands

titen trends

The 8–10 most important stories right now. Cached for 6 hours.

titen trends --region gb

Regions: global (default), us, gb, in, ca, au, br, de, fr, jp, id, ng, sg. Add --refresh to rebuild now.

titen brief

A short digest of the last ~48 hours on any topic. Cached per topic per day.

titen brief "electric cars"

titen brief --list shows suggested topics.

titen tldr

TL;DR, key points and "what's missing" for a page. Cached for 24 hours.

titen tldr https://en.wikipedia.org/wiki/Orion%27s_Belt

titen scam

Checks a message, link or screenshot. Links are checked (domain age, look-alike names, shorteners) but never opened.

titen scam "Your parcel is on hold, pay $1.99 at dhl-redelivery.top"
titen scam --url paypa1-secure.com
titen scam --image ./screenshot.png

You can also pipe text in, for example pbpaste | titen scam.

titen chat

Free conversation. Titen searches news and the web, reads pages, and uses the tools above by itself. In chat: /new, /cost, /exit.

Options for every command

--jsonRaw JSON output (for scripts)
--model <id>Any OpenRouter model with tool support, e.g. anthropic/claude-sonnet-5.5
--refreshSkip the cache
--no-colorPlain output
-h, --helpHelp for a command
-v, --versionShow the version

Watch

Keep an eye on a page (price, stock, an announcement) or a news topic. Titen strips noise like clocks, dates and view counters, and only asks the AI when the content really changed, so quiet days cost nothing.

titen watch add https://store.example.com/product/123 --every 1h --note "price or stock"
titen watch add "GTA 6 release" --every 6h
titen watch daemon
watch add <url | "topic">--every 15m minimum (default 6h), --note what counts as news for you
watch listAll watches and when they run next
watch remove <id>Stop watching
watch run [--force]Check what's due once, then exit (good for schedulers)
watch daemonKeep running and check on schedule
watch log [<id>]Recent changes Titen found
watch testShow a test desktop notification

To check in the background, schedule titen watch run every 15 minutes: Task Scheduler on Windows, launchd on macOS, cron on Linux. The README on GitHub has ready-made commands.

Configuration

titen setup writes ~/.titen/config.json. Environment variables override it:

OPENROUTER_API_KEYYour OpenRouter key
TITEN_MODELModel id (default anthropic/claude-haiku-5.5)
TITEN_SEARCH_ENGINEWeb search engine: exa (default), parallel, perplexity, native
TITEN_HOMEWhere config, cache and watches live (default ~/.titen)
TITEN_NEWS_SOURCE=feedsUse publisher RSS feeds instead of Google News
TITEN_NOTIFY=0Turn off desktop notifications for Watch
TITEN_PLAIN_LINKS=1Print full URLs instead of clickable terminal links

Costs

The website is free to use. The CLI runs on your own OpenRouter credit; with the default model most commands cost a fraction of a cent, and every command prints its cost. Results are cached (trends 6 hours, briefs once per topic per day, TL;DRs 24 hours), and a paid web search (about $0.007) is only used when free sources aren't enough.

Privacy & limits

  • No account and no tracking cookies on the website. Messages and screenshots are sent to the AI model to produce an answer and are not stored.
  • Suspicious links are never opened; Titen only looks up public information about the domain.
  • Some publishers (for example BBC, Reuters, NYT) don't allow automated readers. TL;DR tells you so; try the same story from another site.
  • Pages behind logins (X, TikTok, Instagram, Facebook) or paywalls can't be read.
  • Titen is an AI and can be wrong. Treat it as a careful first look, not the final word.

Self-hosting

Titen is MIT-licensed. Run your own copy from the GitHub repository:

git clone https://github.com/Titen-dev/titen.git
cd titen
npm test
npm start

npm start serves the website on http://localhost:3000 (put your key in .env as OPENROUTER_API_KEY). To deploy on Cloudflare Workers like titenhq.com, run npm run cf:deploy after creating a KV namespace and setting the key as a secret; details are in the README.

FAQ

Why "Titen"?

It comes from titen, the Javanese art of reading signs through patient observation. Read the story.

Which AI model does it use?

By default anthropic/claude-haiku-5.5 through OpenRouter. The CLI accepts any OpenRouter model with tool support via --model or TITEN_MODEL.

Found a bug or have an idea?

Open an issue on GitHub. Pull requests are welcome.
